# 保留物品

下表收錄路線中值得跨區保留的任務起始物、信件、材料、鑰匙和召喚物。帶有任務 ID 的用途可在各段路線找到接、做、交的次序。若任務從物品開啟，先右鍵接取再確認任務日誌。門鑰匙、傳送器與永久召喚物仍有用途時可留著。

物品名優先採用本機《魔獸世界：永恆》台服用戶端與 QuestieDB Forever，缺少繁中紀錄的物品保留英文。任務、地點與用途依 01–05 路線和 06 的選做條目。

每列依序為物品名｜物品ID｜何時拿到（地名）｜何時用到（任務名、地名）。
